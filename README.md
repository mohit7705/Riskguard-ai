# RiskGuard AI

AI-powered return-abuse detection and risk assessment platform.

## Project Goal

RiskGuard AI detects suspicious return behavior using machine learning,
explainable AI, and visual evidence analysis.

## Planned Capabilities

- Return-abuse detection
- Customer and order risk analysis
- Synthetic return-abuse dataset generation
- Machine-learning risk prediction
- SHAP-based explainability
- Gemini Vision analysis
- Unified 0–100 risk scoring
- Human-review workflow
- Merchant dashboard
- Razorpay test integration
